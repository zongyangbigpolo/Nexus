# Git Workflow Skill

Step-by-step procedures for Git operations in SPA repositories.

**Conventions**: See [git-operation](../../instructions/git-operation.instructions.md) for naming rules and formats.

---

## JIRA ID Extraction (MANDATORY)

Before any commit, extract JIRA ID from current branch:

### Method 1: Terminal (preferred)
```bash
git branch --show-current
# Output: feature/SPAOP-10894-AddEpicStoryWorkflow
# Extract: SPAOP-10894
```

### Method 2: Read .git/HEAD
```
# File: {repo_root}/.git/HEAD
# Content: ref: refs/heads/feature/SPAOP-10894-AddEpicStoryWorkflow
# Extract branch after "refs/heads/", then JIRA ID
```

### Priority Order
1. **From branch name** (REQUIRED if on feature/bugfix branch)
2. From explicit user input
3. From JIRA context in conversation

⚠️ **CRITICAL**: JIRA ID in commit **MUST match** branch JIRA ID. Never use placeholder IDs like `{PROJECT}-00000` (e.g., `SPA-00000`) on a named branch.

## Feature Branch Workflow

```bash
# Step 1: Start from latest master
git checkout master
git pull origin master

# Step 2: Create feature branch
# Format: feature/{JIRA-ID}-{PascalCaseName}
git checkout -b feature/SPA-12345-EnableBrowserPolicies

# Step 3: Make changes
# ... edit files ...

# Step 4: Stage changes
git add <files>

# Step 5: Commit (JIRA ID from branch)
git commit -m "SPA-12345 Enable browser policies for customer ABC123"

# Step 6: Push to remote
git push origin feature/SPA-12345-EnableBrowserPolicies

# Step 7: Create PR (via GitHub MCP or UI)
```

---

## Bugfix Branch Workflow

```bash
# Step 1: Start from latest master
git checkout master
git pull origin master

# Step 2: Create bugfix branch
# Format: bugfix/{JIRA-ID}-{PascalCaseName}
git checkout -b bugfix/SPA-12346-FixNullReferenceError

# Step 3: Make changes
# ... edit files ...

# Step 4: Stage and commit
git add <files>
git commit -m "SPA-12346 Fix null reference error in authentication module"

# Step 5: Push and create PR
git push origin bugfix/SPA-12346-FixNullReferenceError
```

---

## Continue on Existing Branch

```bash
# Checkout and sync
git checkout feature/SPA-12345-EnableBrowserPolicies
git pull origin feature/SPA-12345-EnableBrowserPolicies

# Make changes, commit, push
git add <files>
git commit -m "SPA-12345 Update browser policy configuration"
git push origin feature/SPA-12345-EnableBrowserPolicies
```

## AI-Generated Marker

When code is generated by AI agent:
```bash
git commit -m "SPA-12345 Implement user authentication endpoint [AI-Generated]"
```

Append ` [AI-Generated]` at end — helps reviewers identify AI code.

---

## Placeholder JIRA ID (Emergency)

Use `SPA-00000` **ONLY** when:
- On `master` branch directly (rare)
- Branch has no JIRA ID
- Initial repository setup

```bash
git commit -m "SPA-00000 Initial project setup"
```

⚠️ Using placeholder on named branch = convention violation.

## Quick Reference

| Operation | Command |
|-----------|---------|
| Get current branch | `git branch --show-current` |
| Create feature branch | `git checkout -b feature/{JIRA}-{Name}` |
| Create bugfix branch | `git checkout -b bugfix/{JIRA}-{Name}` |
| Commit format | `{JIRA-ID} {Description 10+ chars}` |
| AI commit format | `{JIRA-ID} {Description} [AI-Generated]` |
